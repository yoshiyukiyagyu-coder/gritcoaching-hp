# WordPress（本番サイト）SEO作業手順

対象: https://gritcoaching.co.jp/ （WordPress 6.5.3 ＋ All in One SEO 4.6.1.1 ＋ Site Kit by Google）
根拠: Search Console「検索パフォーマンス」過去3か月（2026-08-08〜11-07）のエクスポート

> メニュー名は日本語表示の管理画面を前提にしています。バージョンによって表記が少し違うことがあります。
> 作業前に、変更前のタイトル・説明文をメモしておくと元に戻せます。

## 1. トップページのタイトル・説明文

トップページは固定ページ（ページID 69）なので、そのページの AIOSEO 設定で変更します。

1. 管理画面 → **固定ページ** → 一覧からトップページ（「フロントページ」と表示されているもの）を開く
2. 編集画面の下にある **AIOSEO 設定** → **一般** タブ
3. 次のとおり入力して **更新**

**投稿タイトル**
```
グリットサッカー（GRITcoaching）｜さいたま市・南与野の小学生・中学生サッカースクール
```

**メタディスクリプション**
```
グリットサッカー（GRITcoaching）は、さいたま市・南与野の小学生・中学生向けサッカースクール。U12フィジカルスキル（金曜）とU15インテリジェンス（木曜）を元Jリーガーが指導。無料体験はLINEから受付中。
```

- 入力欄にすでに `#post_title` などのタグが入っている場合は、消してから上の文を入れます。
- **ソーシャル** タブに Facebook / X 用のタイトル・説明文が入力されている場合は、同じ文に揃えます。
- ※ Googleビジネスプロフィールの「ビジネス名」には「グリットサッカー」を足さないでください。看板やチラシで実際に使っている名前でないとガイドライン違反になります（`docs/seo/google-business-profile.md` 参照）。

## 2. ブログ記事タイトルの後ろの社名を短くする

今は全記事のタイトルの最後に「 | グリットコーチング・ジャパン株式会社」（17文字）が付いており、検索結果で記事名の後半が切れています。設定1か所で全記事に反映できます。

1. 管理画面 → **All in One SEO** → **検索の外観** → **コンテンツタイプ** タブ
2. 一覧の **ブログ**（URLが `/blog/blog/〜` の投稿タイプ）を開く
3. **タイトル** 欄を次のように変更して **変更を保存**

| 変更前（例） | 変更後 |
|---|---|
| `#post_title #separator_sa #site_title` | `#post_title ｜GRITcoaching` |

- `#site_title`（サイト名）そのものは **設定 → 一般** で変えないでください。会社情報（構造化データ）の名前にも使われているためです。
- 保存後、記事を1本開いて、ブラウザのタブにタイトルが「〜｜GRITcoaching」と出るか確認します。出ない記事は、その記事の AIOSEO 設定でタイトルが個別に上書きされています。その記事の「投稿タイトル」欄を `#post_title ｜GRITcoaching` に直してください。
- 「お知らせ」（`/blog/news/〜`）など、ほかの投稿タイプも同じ形に揃えてかまいません。

## 4. 申し込み完了（thanks）ページを検索に出さない

申し込み完了ページは検索から来る人に見せるページではないので、「インデックスしない」設定にします。設定するとサイトマップからも自動で外れます。

1. **固定ページ** → 対象のページを開く
2. **AIOSEO 設定** → **詳細** タブ → **ロボット設定**
3. **デフォルト設定を使用** をオフにして、**インデックスなし（No Index）** にチェック → **更新**

**対象（20ページ）**
```
/lp001/thanks/  /lp002/thanks/  /lp003/thanks/  /lp004/thanks/  /lp005/thanks/
/lp006/thanks/  /lp007/thanks/  /lp008/thanks/  /lp009/thanks/  /lp010/thanks/
/lp011/thanks/  /lp012/thanks/  /lp013/thanks/  /lp014/thanks/  /lp015/thanks/
/lp016/thanks/  /lp017/thanks/  /u12-school/thanks/  /u15-lp01/thanks/  /u15-school/thanks/
```

- **広告用LP（`/lp001/`〜`/lp017/`、`/u15-lp01/`、`/u12-short-202612/`）はこの手順では触りません。** 広告で使っている場合、検索に出すかどうかは担当者と相談して決めてください。内容がほぼ同じLPが多い場合は「インデックスなし」にするのがおすすめです。

## 5. 反映確認とインデックス登録のリクエスト

1. キャッシュ系のプラグインやサーバーのキャッシュを使っている場合は、キャッシュを削除する
2. 各ページをブラウザで開き、右クリック →「ページのソースを表示」で `<title>` と `<meta name="description"` が新しい文になっているか確認する
   - thanksページは `<meta name="robots" content="noindex` が入っていればOK
3. Search Console → 上部の検索欄（URL検査）に次のURLを1つずつ入れる →「**インデックス登録をリクエスト**」
   - `https://gritcoaching.co.jp/`
   - `https://gritcoaching.co.jp/u12-school/`
   - `https://gritcoaching.co.jp/u15-school/`
4. Search Console → **サイトマップ** に `https://gritcoaching.co.jp/sitemap.xml` が送信済みか確認する。なければ送信する

## 6. 効果の確認（2〜4週間後）
